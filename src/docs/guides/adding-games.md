# Adding games

## Add a folder or game file

1. Click **Add** in the library toolbar.
2. Click **Choose folder…** for a game's folder, or **Choose game file…** for its game file. You can also drop a single game folder or file onto the library window.
3. Check **Game file**. If several files were found, choose the one that starts the game.
4. Check the suggested match. Use **Search VNDB** to search by title or paste a VNDB link or ID. Select a result and click **Next**.
5. Check **Title**, **Game file** and **Mode**, then click **Add**.

Game data and covers come from VNDB. If there is no suitable match, click **Add without VNDB**, enter **Title**, check the game file and mode, then click **Add**.

## Add a Steam game

1. Click **Add**, then **Add a Steam game**.
2. Enter **Title** and the numeric **Steam app ID**. No game file is needed.
3. To look up its metadata, click **Find on VNDB**, select a result and click **Next**.
4. Click **Add**. Select the game and click **Play** to start it through Steam.

For several games, use [folder import](/docs/guides/folder-import).
