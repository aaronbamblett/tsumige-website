# Privacy

Tsumige keeps your library in a local folder.
It has no account and no telemetry.

Tsumige contacts api.vndb.org when you search or refresh metadata.
It downloads images from t.vndb.org.

This website is static. It is served by GitHub Pages behind Cloudflare.
