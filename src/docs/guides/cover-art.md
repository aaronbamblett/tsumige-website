# Cover art

1. Select a game in the library.
2. Open the game menu (⋮) and click **Change art…**.
3. Choose **Cover** or **Background**. Covers come from VNDB packages and, with your own free API key, SteamGridDB. SteamGridDB also supplies backgrounds.
4. Click an image, or click **Choose file…** to use your own image. Tiles show the whole image with its size.
5. The preview shows the part the library uses. Drag the frame to choose it (**Drag to reposition**). Covers are 2:3.
6. Click **Save** to apply your choices. **Cancel** closes the dialog without applying them.

You can choose both a cover and a background before saving.

Put the SteamGridDB API key in Settings → Library, or click **Set API key** in Change art.
