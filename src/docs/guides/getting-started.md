# Getting started

1. [Download Tsumige](/download/) and follow the install steps for your platform.
2. Open Tsumige and click **Add** in the top bar.
3. Click **Choose folder…** and select one game's folder. Check the suggested game file and match. Game data and covers come from VNDB.
4. Select the matching result and click **Next**. Check **Title**, **Game file** and **Mode**, then click **Add**.
5. Select the game in your library and click **Play**.

Linux offers **Proton**, **Wine**, **Native** and **Steam** modes. macOS and Windows offer **Native** and **Steam** only. On Linux, **Proton** needs `umu-run` available on `PATH`.

## The library

On a wide window, the logo, search, sort, **All** / **Favourites**, **Filter**, **Add**, Settings and the window buttons share one bar. Narrow windows get two rows.

Active filters show as chips above the grid, each with ×, followed by **Clear all**. Examples are **Hide adult**, a tag and **Developer: X**. Clicking a developer's name in the Info tab filters by that developer.

English text uses the bundled Inter. Other scripts use the system's fonts.

## The game menu

Open the game menu (⋮) on a tile for **Edit…**, **Change art…**, **Open on VNDB** and **Remove from library…**. **Edit…** changes **Title**, **Original title**, **Developers** and **Release date**. **Release date** takes YYYY-MM-DD, YYYY-MM or YYYY. Edited fields are kept when VNDB data is refreshed. **Use VNDB value** puts VNDB's value back. **Remove from library…** removes the game from Tsumige only. Its files stay where they are.
