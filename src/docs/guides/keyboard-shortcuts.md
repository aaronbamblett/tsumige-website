# Keyboard shortcuts

On desktop and the web, Tsumiru has shortcuts for getting around and for reading. Open **Settings → Keyboard shortcuts** to see the full list in the app. The screen appears only where there's a keyboard, so it's hidden on phones and tablets. It's a reference list — the shortcuts are fixed and can't be rebound.

## Getting around

| Shortcut | Action |
|---|---|
| `Esc`, `Alt` + `←`, or the mouse back button | Go back |
| `Ctrl` + `F` or `Ctrl` + `P` | Open search |
| `Ctrl` + `L` | Open the library *(desktop only)* |
| `Ctrl` + `J` | Open downloads *(desktop only)* |

`Ctrl` + `F` and `Ctrl` + `P` open [Quick Search](/docs/faq/settings#what-is-quick-search), which searches your library, jumps around the app, and hands off to source search.

## In the reader

| Shortcut | Action |
|---|---|
| `←` or `A` | Previous page |
| `→` or `D` | Next page |
| `Home` | First page |
| `End` | Last page |
| `,` | Previous chapter |
| `.` | Next chapter |
| `Esc` | Show or hide the reader menu |
| `Space` | Start or stop [auto-scroll](/docs/guides/reader-settings#auto-scroll-and-auto-advance) *(long-strip modes)* |
| `=` / `−` | Auto-scroll faster / slower *(long-strip modes)* |

In right-to-left manga, the previous- and next-page keys follow the reading direction.
