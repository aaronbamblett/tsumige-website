# Download

All builds are on the [releases page](https://github.com/aaronbamblett/tsumige/releases).

## Linux: Flatpak

Add the Tsumige repository, then install the app.

```sh
flatpak remote-add --if-not-exists tsumige https://flatpak.tsumige.app/index.flatpakrepo
flatpak install tsumige app.tsumige.Tsumige
```

## Linux: AppImage

1. Download the `.AppImage` file from the [releases page](https://github.com/aaronbamblett/tsumige/releases).
2. Make it executable: `chmod +x` followed by the file name.
3. Run it.

## macOS

1. Download the zip file from the [releases page](https://github.com/aaronbamblett/tsumige/releases) and unzip it.
2. The app isn't signed with an Apple Developer ID, so on first launch right-click Tsumige.app and choose **Open**.

## Windows

1. Download the zip file from the [releases page](https://github.com/aaronbamblett/tsumige/releases) and unzip it.
2. Run `tsumige.exe`.
